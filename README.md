# Food Ordering & Billing System

A terminal-based Food Ordering and Billing System built using TypeScript.

## Features

- View food menu
- Create Guest or Member customer
- Add items to cart
- Update item quantity
- Remove items from cart
- Calculate subtotal
- Apply membership discount
- Apply additional discount above ₹2000
- Calculate 5% GST
- Pay using Cash, Card or UPI
- Generate final bill
- Change order status
- Search food items

## Technologies Used

- TypeScript
- Node.js
